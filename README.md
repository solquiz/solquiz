# 무엇일까요? 퀴즈 놀이 (웹 · 사지선다 버전)

힌트를 **음성으로 듣고**, 보기 4개(그림 + 글씨) 중에서 **눌러서 고르는** 퀴즈입니다.
아이폰·안드로이드 브라우저에서 동작하고, 앱스토어·서명·7일 만료가 없습니다.

## https 가 필요한가요?  →  **필요 없어요.**

마이크를 쓰는 "음성 인식"만 https 가 필수였고, 이 버전은 마이크를 쓰지 않습니다.
음성 **안내**(힌트 읽어주기)는 http 주소에서도 동작해요. 그래서:

- 맥에서 서버를 켜고, 같은 와이파이의 휴대폰에서 `http://맥의IP:8000` 으로 바로 열어볼 수 있습니다. (서버를 켜면 터미널에 휴대폰용 주소가 표시돼요)
- 마이크 권한 팝업, 받아쓰기 설정, Safari 전용 제한, 인터넷 연결(음성 인식용)이 모두 사라졌습니다.
- 홈 화면에 추가해서 전체화면 앱처럼 쓸 수도 있어요(`manifest` 가 `standalone`).

> 단, 앞으로 브라우저가 보안 정책을 강화해 음성 안내도 https 에서만 허용하게 될 가능성이 논의된 적이 있어요.
> 집 밖에서도 쓰거나 오래 쓸 거라면 무료 https 호스팅(Netlify / Cloudflare Pages / GitHub Pages)에 올려 두는 게 안전합니다.
> 그리고 어떤 방식이든 **웹서버는 필요해요.** `index.html` 을 더블클릭(file://)하면 퀴즈 파일을 못 읽습니다.

## 1. 실행해 보기 (Mac)

1. 터미널에서 **이 폴더 안으로** 이동: `cd 폴더경로/kids-quiz-web-choice`  (그 폴더 안에 `index.html` 이 보여야 해요)
2. `python3 serve.py`  ← 예전의 `python3 serve.py` 대신 이걸 쓰세요 (아래 이유 참고)
3. 터미널에 나온 주소를 브라우저에서 열기 (맥: `http://localhost:8000`, 휴대폰: 터미널에 표시된 `http://192.168...:8000`)

서버를 켜면 터미널에 **지금 보고 있는 폴더, 퀴즈 개수, 이미지가 없는 문제**가 바로 표시돼요.

**왜 `serve.py` 인가요?** 기본 서버(`http.server`)는 브라우저가 옛 `quizzes.json`/그림을 다시 쓰는 걸 막지 않아서,
파일을 바꿨는데 화면은 그대로인 일이 생겨요. `serve.py` 는 캐시를 꺼서 **고치고 새로고침하면 바로 반영**돼요.
포트가 이미 사용 중이면 `python3 serve.py 9000` 처럼 번호를 바꿔 실행하세요.

### 고쳤는데 반영이 안 될 때 → `/check.html` 부터

브라우저에서 `http://localhost:8000/check.html` 을 열어 보세요. 아래를 한 번에 알려줘요.
- 지금 서버가 읽고 있는 `quizzes.json` 의 **문제 수·카테고리별 개수**와 파일 수정 시각
- JSON 형식 오류가 있으면 **몇 번째 줄**인지 (쉼표 누락·마지막 쉼표 자동 감지)
- 문제별 그림이 실제로 나오는 썸네일, **이미지가 없는 문제 목록**

| check.html 에서 보이는 것 | 의미 / 해결 |
|---|---|
| 문제 수가 내가 넣은 것보다 적음 | 다른 폴더를 서버로 열고 있음. 터미널을 `kids-quiz-web-choice` 폴더 안에서 다시 열고 `python3 serve.py` |
| "형식 오류 — ○○번째 줄" | 그 줄 끝의 쉼표 누락, 또는 마지막 항목 뒤 쉼표 |
| 이미지 없음 목록 | JSON 의 `imageName` 과 `images/` 파일 이름이 **글자 하나까지** 같아야 해요 (아래 참고) |
| 모두 정상인데 앱 화면만 이상 | 브라우저 강력 새로고침: 맥 `⌘ + Shift + R` / 휴대폰은 탭을 닫고 다시 열기 |

**Xcode 에서 가져온 그림은 이름이 다를 수 있어요.** `Assets.xcassets/dump_truck.imageset/` 안의 실제 파일명이
`dump_truck.png` 가 아닐 수 있습니다(`Image.png`, `dump_truck@2x.png` 등). **폴더 이름이 아니라 폴더 안 PNG 의 파일명**을
`dump_truck.png` 로 바꿔서 `images/` 바로 아래에 두세요. `.jpg`, `.PNG`(대문자) 확장자도 안 됩니다.
(서버를 켤 때 비슷한 이름의 파일이 있으면 "비슷한 파일 발견" 으로 알려줘요.)

## 2. 이 버전의 진행 방식

1. 카테고리 선택 (버튼은 `quizzes.json` 의 category 로 자동 생성 + 랜덤)
2. **힌트를 음성으로 읽어줌** (위쪽 검은 무대에는 **어떤 문제든 똑같이 내가 지정한 그림** — 기본은 `images/question.png` 의 "?" 그림)
3. 힌트가 끝나면 **보기 4개** 등장 — 각 보기는 **그림 + 이름 글씨**
4. 하나를 누르면
   - **정답** → 정답 화면 (위쪽 그림이 **정답의 진짜 컬러 그림**으로 바뀌며 공개 + 별 + 박수 소리 + "정답입니다!") → 계속하기 / 그만하기
   - **오답** → 그 보기는 흐려지고 ✖ 표시, "다시 한번 생각해 보세요" 음성·문구 → **남은 보기에서 다시 고르기**
5. "힌트 다시 듣기" 버튼으로 언제든 힌트를 다시 들을 수 있음 (틀린 표시는 유지)

### 보기는 어떻게 뽑히나요?
- 정답 1개 + 오답 3개. 오답은 **같은 카테고리에서 먼저** 뽑고, 모자라면 다른 카테고리에서 채웁니다.
- 이름이나 그림이 같은 문제는 보기에 같이 나오지 않습니다.
- 문제 수가 4개보다 적으면 있는 만큼만(최소 2개) 보여줍니다.

### 헷갈리는 문제가 같이 나오지 않게 하기 (`notWith`)
예를 들어 "청소차"와 "쓰레기수거차"가 한 화면에 같이 나오면 아이가 헷갈리죠.
이럴 땐 `quizzes.json` 의 한쪽 문제에 `notWith` 를 적으면 **절대 같이 나오지 않습니다**(반대쪽에 안 적어도 됨).

```json
{
  "id": "car_054",
  "category": "car",
  "answer": "청소차",
  "notWith": ["car_033"],
  "hints": ["..."],
  "imageName": "street_sweeper"
}
```

## 3. 폴더 구조

```
kids-quiz-web-choice/
├── serve.py                ★ 실행: python3 serve.py (캐시 끔 + 폴더/이미지 점검 + 휴대폰 주소 표시)
├── check.html              데이터 점검 페이지 (quizzes.json 줄 번호 오류, 이미지 누락 확인)
├── index.html              화면 3개(시작 / 카테고리 / 퀴즈)의 뼈대
├── css/style.css           색, 크기, 검은 무대, 보기 카드, 버튼 모양
├── js/
│   ├── app.js              ★ 앱의 두뇌: 화면 전환·퀴즈 진행·보기 만들기·정답 판정
│   ├── tts.js              음성 안내(힌트/결과 읽어주기)
│   ├── data.js             quizzes.json 읽기 + 오류 검사
│   ├── check.js, jsonhint.js   점검 페이지용
├── data/quizzes.json       ★ 퀴즈 문제 (샘플 6개)
├── images/                 ★ 문제 그림 PNG (샘플 6장) + question.png (문제 중 보여줄 고정 "?" 그림)
├── sounds/clap.wav         정답일 때 박수 소리 (임시 합성음 — 원하는 파일로 교체)
├── icons/, manifest.webmanifest   홈 화면 아이콘/바로가기
```

> 음성으로 정답을 말하는 이전 버전(`stt.js`, `matcher.js` 포함)은 앞서 받은 `kids-quiz-web.zip` 에 그대로 있습니다.

## 4. 퀴즈 추가하는 법 (코드 수정 없음)

### 문제 추가: `data/quizzes.json`
**기존 `quizzes.json` 을 그대로 덮어써도 됩니다.** `acceptedAnswers` 는 이제 쓰지 않지만 남아 있어도 무시되고,
새로 추가하는 문제에는 안 적어도 됩니다.

```json
{
  "id": "object_011",
  "category": "object",
  "answer": "모자",
  "hints": ["나는 머리 위에 써요.", "햇빛이나 추위를 막아줘요."],
  "imageName": "hat"
}
```
- 문제와 문제 사이에는 쉼표(`,`), 맨 마지막 문제 뒤에는 쉼표 없음.
- 보기 카드에 **`answer` 가 그대로 글씨로 표시**됩니다. 아이가 읽기 쉬운 이름으로 적어주세요.
- 보기를 만들려면 **전체 문제가 최소 4개** 이상 있는 게 좋습니다.

### 문제 중에 보여줄 고정 그림 바꾸기
- 쓰고 싶은 그림을 **`images/question.png` 라는 이름으로 덮어쓰거나**, `js/app.js` 맨 위 `CONFIG.QUESTION_IMAGE` 에 다른 경로(예: `'images/mystery.png'`)를 적으세요.
- 이 그림은 **실루엣 처리 없이 원래 색 그대로** 보여요. 투명 배경 PNG 를 권장합니다.
- 위쪽 무대 배경은 **검은색**이에요. 그림에 검은색/어두운 부분이 많으면 안 보이니 밝은 색을 쓰거나, `css/style.css` 맨 위 `--stage-dark` 값을 바꿔 배경색을 바꾸세요. (정답 공개 후 배경은 `--stage-light`)
- 파일이 없으면 ❓ 가 대신 나오고, 정답 공개 때는 정상적으로 진짜 그림이 나옵니다.

### 그림 추가: `images/이름.png`
- **투명 배경 PNG** 를 권장합니다. (`QUESTION_IMAGE` 를 `''` 로 두고 실루엣 방식을 쓸 때는 배경이 투명하지 않으면 실루엣이 네모로 나옵니다.)
- **보기 카드와 정답 공개 화면에 쓰이므로**, 모든 문제의 그림이 있어야 해요. 없으면 그 자리에 ❓ 가 나옵니다.
- 기존 iOS 앱의 그림: `Assets.xcassets/○○.imageset/○○.png` 파일들을 `images/` 로 복사하세요.

### 새 카테고리
`quizzes.json` 에 `"category": "animal"` 처럼 새 이름을 쓰면 버튼이 자동으로 생깁니다(기본 모양 🎁).
이름/이모지/색을 꾸미려면 `js/app.js` 맨 위 `CATEGORY_META` 에 한 줄 추가:
```js
animal: { label: '동물', emoji: '🐶', color: '#f59e0b' },
```

## 5. 자주 바꾸는 설정 (`js/app.js` 맨 위 `CONFIG`)

| 값 | 의미 |
|---|---|
| `HINT_GAP_MS` | 힌트와 힌트 사이 간격 (1000 = 1초) |
| `CHOICE_COUNT` | 보기 개수 (기본 4) |
| `QUESTION_IMAGE` | 문제가 나가는 동안 위쪽 무대에 **모든 문제에 똑같이** 보여줄 그림 경로 (기본 `'images/question.png'`). 정답 그림의 흰 실루엣을 보여주던 이전 방식으로 되돌리려면 `''` (빈 따옴표) |
| `STAGE_BACKGROUND` | 문제 중 `?` 그림 **뒤에** 깔 배경 그림 경로 (기본 `'images/stage_bg.png'`). 그 이름으로 파일을 넣으면 자동 적용, 파일이 없으면 검정 배경. 정답 공개 때는 밝은 배경으로 바뀝니다 |
| `SHOW_SILHOUETTE` | `false` 로 바꾸면 정답 공개 전까지 위쪽 무대 자체를 숨기고 힌트+보기만 보여줌 |
| `DISTRACTORS_SAME_CATEGORY_FIRST` | `false` 면 오답 보기를 전체 문제에서 무작위로 뽑음 |
| `SHOW_HINT_TEXT` | `true` 면 힌트를 글자로도 보여줌 (개발 확인용) |

음성 속도/높낮이는 `js/tts.js` 의 `speak()` 안 `rate`(1이 보통)·`pitch` 로 조절합니다.

## 6. 문제 해결

| 증상 | 확인 |
|---|---|
| "퀴즈 파일을 읽지 못했어요" | `/check.html` 을 열면 오류 줄 번호가 나와요. 대부분 쉼표 누락 |
| 파일을 바꿨는데 화면이 그대로 | `python3 serve.py` 로 실행(캐시 꺼짐) + 강력 새로고침. `/check.html` 로 서버가 읽는 파일 확인 |
| 소리가 안 남 | 시작 버튼을 직접 눌렀는지, 기기 미디어 볼륨, 아이폰 무음 스위치 확인 |
| 한국어 목소리가 어색/없음 | 기기의 한국어 음성(TTS) 설정 확인. 안드로이드는 Google 음성 서비스에 한국어 음성 데이터 설치 |
| 그림 자리에 ❓ | `images/` 에 같은 이름의 PNG 가 없음 (콘솔에 파일명 표시) |
| 위쪽 그림이 안 보임 | 그림이 검은색 위주인지 확인 (무대 배경이 검정). 밝은 색 그림을 쓰거나 `--stage-dark` 변경 |
| (실루엣 방식 사용 시) 실루엣이 네모 | PNG 배경이 투명하지 않음 |
| 보기가 4개보다 적음 | 전체 문제 수가 부족하거나 `notWith`/같은 이름·그림 규칙 때문에 후보가 없음 |
| 화면이 작은 폰에서 잘림 | 위아래로 스크롤하면 됩니다 (작은 화면에서는 자동 스크롤) |
